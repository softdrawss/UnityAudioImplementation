# How can I make the ambience sound of my game more interesting?
There are different possible ways to do it. 

If you are looking for reverb in certain zones, add a Reverb Zone, choose a preset that you like and set the minimum and maximum distance you need.

In case you want to create different ambiences according to the space, you can choose between using a [collider](./collider/ambience_collider.md) or a [spline](./spline/ambience_spline.md)
